FARM PLANNER - install as an app (works offline, no browser bar)

1. Put ALL the files in this folder on any free HTTPS web host
   (Netlify Drop, GitHub Pages, Cloudflare Pages...). Keep them together.
2. Open the web address once on your phone, while online.
3. iPhone/iPad (Safari): Share > Add to Home Screen.
   Android (Chrome): menu > Install app / Add to Home screen.
4. Open it from your home screen. It now runs full-screen and offline.

Your plans are saved on that device only - use Export to back them up.
To publish an update later, re-upload the files and change CACHE in sw.js (farm-planner-v2).
